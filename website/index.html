Programming language

Rizo Lang

Describe your data, who may do what, and your pages in a short .rz file. The compiler turns it into a PostgreSQL database, a TypeScript server and web pages.

  • No raw SQL and no HTML, so SQL injection and cross-site scripting can't be written
  • Accounts, passkeys, roles, rate limits and an audit log built in
  • A spec small enough for any AI model to learn, and errors that say how to fix them
  • Open source under Apache 2.0, on npm as rizolang

blog.rz (excerpt)auth User by email roles admin, editor

model User {
  email: Email unique private
  password: Password min 12
  name: Text max 100
}

model Post {
  author: User
  title: Text min 1 max 200
  body: Text
  published: Bool
}

api PATCH /api/posts/:id -> Post.public {
  requires login
  requires owner author
  return db.Post.update(id, body)
}

Made to work together

AI models are good at writing code and bad at remembering every security rule. Rizo keeps you in charge of what the model does; Rizo Lang makes sure what it writes is safe by construction.

01

You describe the app

Ask Rizo for a feature in plain language, in VS Code, with the model you prefer.

02

The model writes Rizo Lang

The language fits in a short spec, so even small models write it well. Access rules are part of the syntax.

03

The compiler checks it

Every error names the line and the fix, and rizolang audit flags risky choices. The model reads them and corrects itself.

04

You review and ship

Rizo shows every change as a diff. You get a PostgreSQL schema, a TypeScript server and pages you can run anywhere.

Since Rizo 0.7.0 this loop is built in: Rizo recognizes .rz files, loads the language spec automatically, and shows the compiler's checks in the editor and to the model.

What both are built on

The same three rules shape every decision in both projects.

You hold the keys

Rizo uses your own provider key, stored in your OS keychain, and talks to the provider directly. Rizo Lang apps run on your own servers. Nothing routes through us.

Safe by default

Rizo asks before it writes or runs anything and never reads your secrets without asking. Rizo Lang makes injection, missing access checks and plain-text passwords impossible to write.

Source you can read

Both are developed in public on GitHub, with over a thousand automated tests between them, CodeQL scanning, and releases published straight from CI. Read exactly how they handle your code before you trust them with it.
