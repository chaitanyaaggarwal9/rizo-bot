Rizo for VS Code

The AI coding assistant that runs on your key.

Rizo reads your code, plans the work, edits files, runs commands and uses MCP tools, with the model you pick. Every write shows a diff, every command asks first, and every reply can be undone.

How a task runs

Rizo works like a careful colleague: it looks before it changes anything, tells you what it is doing, and leaves you the final say.

01

Ask

Describe the change. Attach files, mention workspace files, or paste a screenshot for models that support images.

02

Investigate

Rizo searches and reads the code without interrupting you, and keeps a live checklist for multi-step work.

03

Change, with approval

Each edit opens as a diff and each command asks first. Destructive commands always warn, whatever you allowed before.

04

Review or undo

A reply that changed files gets an Undo button that restores them, with a warning if you edited them since.

Everything in the box

The features you'd expect from a modern coding agent, built so you can see and stop what it does.

Plan mode

Switch the composer to Plan and Rizo only reads and investigates, then proposes a plan. One click runs it.

Undo any reply

The last 20 replies in each chat can be undone, including replies you stopped or that failed partway.

Search without prompts

Text search, file search and folder listing stay inside the workspace, skip ignored and secret files, and need no approval.

Code navigation

Go to definition, find references and call hierarchy through your language server, not a text match.

MCP servers

Connect GitHub, a database, your docs or any Model Context Protocol server, local or remote. Every call asks first.

Inline edit

Select code, press Cmd+Alt+K, say what to change, then keep or undo the result in place.

Autocomplete

Optional suggestions as you type, accepted with Tab. Off by default, because each one is a paid request.

Terminal and git

Runs commands in your workspace with a time limit, capped output, and credentials withheld from the environment.

Skills

Built-in guidance for coding, debugging, testing, security, git and code review, loaded only when the task needs it.

Project rules

Put your conventions in .rizo/instructions.md. Rizo asks you to approve them, and asks again when they change.

Slash commands

/commit, /review and /test start a full, guided task in one line.

Rizo Lang built in

.rz files are highlighted and checked as you type with your project's compiler. The model gets the language spec and checks its own changes.

Chats that last

Named chats with history, automatic summaries of long ones, and undo when you delete one by mistake.

Starts cheap, steps up when it matters

A chat begins on a faster, cheaper model unless your first message clearly needs more. If a reply struggles, Rizo offers a one-click retry on the strongest model of the same company. An effort control sets how hard models that can reason should think.

You always see the cost

Each reply shows its tokens. The chat shows its total, and the panel shows today's tokens and this month's cost across every chat, using the exact cost your provider reports.

No reply limits

A reply runs until the model is finished or you press Stop. Set your own caps on steps or tokens if you want them.

Where your code goes

When you send a message, Rizo sends your prompt and the code it needs straight from your machine to the provider you chose. That's the only place it goes.

No telemetry

The extension doesn't collect usage data. Besides your provider, it only contacts OpenRouter's public model list and MCP servers you add yourself.

Your provider's rules apply

What happens to a request after it reaches the provider, including retention and training, is set by that provider and your account settings there.

Secrets stay out

.env files and keys need approval to read and are never searched or autocompleted. Secrets in command output are redacted.

Safety you don't have to configure

An AI agent can be wrong, or be tricked by text it reads. Rizo is built so that neither turns into damage without you agreeing to it.

When Rizo wants toWhat happens
Read or search codeRuns straight away, inside your workspace. Files that usually hold secrets ask every time.
Write or edit a fileShows a diff and asks. Edits to .vscode, .git, .github and other folders that control automation always ask.
Run a commandAsks first. Force-push, hard reset, rm -rf, piping downloads into a shell and similar commands always warn.
Use an MCP toolAsks every time and shows the arguments, unless you allowed that one tool in this project.
Use another folderOnly after you grant it. Your home folder, ~/.ssh and system folders can't be granted.

Rizo only runs in folders you trust, and a repository can't change its security settings or add MCP servers. Read the full security model.

Up and running in two minutes

All you need is VS Code and a key from OpenRouter, or an Azure or Bedrock account.

01

Install

Search for "Rizo" in the Extensions view, or install it from the Marketplace.

02

Add your key

Create a key at openrouter.ai. Free models work without credit. Or run "Rizo: Connect Azure AI Foundry" or "Connect Amazon Bedrock".

03

Open the chat

Run "Rizo: Open Chat" from the Command Palette, pick a provider, and describe what you want to build.

Questions

If something isn't answered here, open an issue.

What does Rizo cost?

Rizo itself is free. You pay your AI provider directly for the tokens you use, at their prices, and Rizo shows you the cost as you go. Free models on OpenRouter cost nothing.

Does Rizo see or store my code?

No. There is no Rizo server. Requests go from your editor to the provider you chose. Chats are stored locally in VS Code's storage on your machine.

Can it break my project?

Every write needs your approval (or your explicit "Always Allow" for the project), dangerous commands always warn, and you can undo the file changes of any recent reply. Commands it ran, such as installs, can't be undone, which is why they ask first.

Which model should I use?

Start with a provider's everyday model. Rizo picks a cheaper model for simple chats and offers the strongest one when a task struggles. For autocomplete, choose a fast, cheap model.

Is it open source?

Rizo is source-available under the Apache License 2.0 with the Commons Clause: you can read, use (including at work), modify and share it, but not sell it. Rizo Lang is open source under Apache 2.0.

Does it work with Rizo Lang?

Yes, since 0.7.0. .rz files are highlighted, chats about Rizo Lang load the official spec, and with rizolang installed in your project, errors and audit warnings show in the editor with a Fix with Rizo quick fix. Rizo asks once per project before it runs the compiler, and only runs its read-only audit.
